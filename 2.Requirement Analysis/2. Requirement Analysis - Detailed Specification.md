# Phase 2: Requirement Analysis
**Project:** Auto Ticket Classification using Flow Designer  
**Platform:** ServiceNow Cloud Platform (Global Scope)  

---

## 1. Phase Overview
The Requirement Analysis Phase translates the user needs identified in Phase 1 into formal functional specifications, non-functional performance benchmarks, technical stack definitions, and agile user stories.

## 2. Key Deliverables in this Folder
1. `Customer Journey Map.docx`: Comprehensive six-stage journey mapping comparing the legacy manual triage experience against the transformed Flow Designer experience.
2. `Solution Requirements.docx`: Complete Functional Requirements (FR-1 to FR-8) and Non-Functional Requirements (NFR-1 to NFR-6).
3. `Technology Stack - Template.docx`: Complete architectural breakdown of Presentation, Automation, Data, Messaging, and Deployment tiers.
4. `Data Flow Diagrams and User Stories.docx`: DFD Levels 0, 1, and 2, along with 10 detailed Agile User Stories (USN-1 to USN-10).

## 3. Core Functional Requirements (FR) Summary
- **FR-1 (Custom Table):** Dedicated table `Incident WorkFlow` (`u_incident_workflow`).
- **FR-2 (Auto-Numbering):** Unique identifier starting with `INC00500` (Prefix `INC`, 5 digits).
- **FR-3 (Data Model):** Caller, Short Description, Description, Category, Subcategory, State, Assigned Group, Assigned To.
- **FR-4 (Choice Dependencies):**
  - `Network` -> `Wi-Fi`
  - `Hardware` -> `Projector`
  - `Access` -> `Forgot Password`
  - `Performance` -> `Slow Compter`
- **FR-5 (Flow Trigger):** Record Created on `u_incident_workflow` where `Category is empty`.
- **FR-6 (Keyword Evaluation):** Conditional branches evaluating Short Description for Wi-Fi, Projector, Password, Slow Computer.
- **FR-7 (Outbound Email):** Automated email dispatched to `Caller.email` with subject *"Your Request for the issue has been submitted."*
- **FR-8 (Update Set Packaging):** All artifacts captured in `Project Update Set` and exported to XML.
